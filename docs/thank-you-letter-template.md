# Шаблон благодарственного письма за выполненный проект

Документ для деловой переписки после сдачи работ. Замените плейсхолдеры в квадратных скобках и удалите этот блок инструкций перед отправкой.

**Плейсхолдеры**

| Поле | Пример |
|---|---|
| `[ОРГАНИЗАЦИЯ_ОТПРАВИТЕЛЯ]` | ТОО «…» / ИП … |
| `[АДРЕСАТ_ФИО]` | Иванов Иван Иванович |
| `[АДРЕСАТ_ДОЛЖНОСТЬ]` | Генеральный директор |
| `[АДРЕСАТ_ОРГАНИЗАЦИЯ]` | ТОО «Miru Systems» |
| `[НАЗВАНИЕ_ПРОЕКТА]` | Miru Remote (пилот) |
| `[ПЕРИОД]` | март–апрель 2026 |
| `[РЕЗУЛЬТАТ_1]` | контур согласия → видео → заключение |
| `[РЕЗУЛЬТАТ_2]` | Admin onboarding МО без SQL |
| `[КОНТАКТ]` | name@company.kz, +7 … |

## Краткие правила оформления

1. Одна страница — достаточно; без рекламных абзацев.
2. Указывайте конкретные результаты, а не общие слова («отлично», «профессионально»).
3. Для официальной бумаги: бланк организации, исходящий номер, подпись и печать (по локальным правилам).
4. Для email: тема письма — `Благодарность за проект «[НАЗВАНИЕ_ПРОЕКТА]»`.
5. Перед отправкой сверьте формулировки с актом / протоколом приёмки, чтобы не обещать объём вне сдачи.
