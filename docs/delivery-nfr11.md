# Поставка и эксплуатация — НФТ §11 (Miru Remote)

Документ для сдачи пилотного контура. Актуализируется вместе с `docs/architecture.md` (НФТ 11.1).

## 1. Состав поставки

| Компонент | Назначение | Порт (dev) |
|---|---|---|
| `apps/api` | NestJS API, Prisma, интеграции | 3000 |
| `apps/web-staff` | Медперсонал (ПМД) | 5173 |
| `apps/web-admin` | Внедрение МО, без ПМД | 5174 |
| `apps/miniapp` | Пациент / витрина | 5175 |
| `deploy/docker-compose.yml` | Postgres, Redis, MinIO, LiveKit | — |
| `docs/architecture.md` | Архитектура и ИБ | — |

Секреты **не** входят в поставку (`.env` вне git).

## 2. Роли и контуры доступа

- **Клинический контур** (`web-staff`, miniapp): AccessLog на чтение ПМД; DenyTechPmdGuard.
- **Техконтур** (`web-admin`): только метаданные МО, пользователи (email/роль/2FA), чек-лист, TechActionLog. **Нет** текстов заключений, чатов, записей сессий.
- Техроли: `TECH_IMPLEMENTATION`, `TECH_SUPPORT`, `PLATFORM_ADMIN`.

## 3. Подключение МО без SQL (сценарий Д)

1. Войти в Admin (`tech@…` + TOTP).
2. Создать МО (БИН, названия).
3. Добавить отделение.
4. Создать `ORG_ADMIN` и `CONSULTANT` (или bulk JSON).
5. «Опубликовать оферту/согласия v1».
6. Настроить МИС (`manual` до выдачи API) и при необходимости витрину.
7. Отметить ручные пункты чек-листа (хостинг РК, SMS/Telegram, NCALayer, dry-run).
8. Gate: перевод в `testing` / `live` **только** если все required-пункты done.

## 4. Журналы

- `AccessLog` — доступ к ПМД (fail-closed на чувствительных чтениях).
- `TechActionLog` — действия админ-панели (создание МО, пользователей, смена статуса).
- Доказательная база: consent acceptance, status history, conclusion versions — append-only.

## 5. ЭЦП и МИС

- Подпись: NCALayer + bind ИИН сертификата к учётке консультанта.
- МИС: `MisPort` → `manual` | `mock` | stubs `zhetysu`/`damumed`. Production-адаптеры — после спек API заказчика.

## 6. Критерии приёмки пилота (Remote)

- [ ] МО создана через Admin без SQL.
- [ ] Чек-лист блокирует `live` при незакрытых required.
- [ ] Случай: согласие → слот → сессия (gate записи) → заключение → NCALayer/dev → пациент получил.
- [ ] Досье случая собирается ≤ 60 с.
- [ ] Реестр «оказано vs внесено» для ручного моста.
- [ ] Tech action log пишет операции внедрения.
- [ ] Техроль не читает ПМД (проверка DenyTechPmdGuard).

## 7. Вне объёма 4 недель Remote

FrontDesk; полный дашборд заведующего [Ж]; пакетное досье за период; production МИС без спек.

## 8. Контакты эксплуатации

Заполняется заказчиком: admin СУБД РК, хранение ключей шифрования, SMS/Telegram, площадка аттестации.
